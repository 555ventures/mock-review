# @555/mock-review

The mock reviewer for the spec pipeline's mock app: the `mock-review` CLI (`contract`, `check`, `sweep`, `answer`, `serve`) and the served reviewer page, satisfying contract v1.

Install into a mock app with `npm i -D github:555ventures/mock-review#v1` — `dist/` is committed, so no build runs on the host.

Gate: `npm run check` (typecheck, lint, tests).
